吸热式气氛与 RX 发生器

RX 发生器结构详解：反应罐、催化剂、混合系统与冷却

一句话答案

一台吸热式（RX）气体发生器主要由六部分构成：空气/燃气比例混合系统、混合气泵、装有镍催化剂的耐热合金反应罐、加热系统（电或燃气）、出口冷却器，以及包括露点/碳势测量、温度控制和安全联锁的控制系统。产气质量取决于空燃比精度、反应温度、催化剂活性和冷却速度。

  • 混合系统：精确控制空气与燃气比例，是产气质量的源头
  • 反应罐 + 镍催化剂：在高温下完成裂解
  • 加热系统：维持吸热反应所需温度
  • 冷却器：快速冷却防止炭黑
  • 控制与联锁：露点/碳势控制、温度控制、火焰与压力保护

整体流程

空气 + 燃气 → 比例混合 → 混合气泵加压 → 反应罐（高温催化裂解）→ 冷却器 → 过滤/稳压 → 送往热处理炉

1. 空燃比混合系统

这是决定气体质量的关键环节。空气与燃气经过流量计、调节阀（或比例阀）按设定比例混合，比例微调用于控制出口露点或碳势。

  • 传统方式：机械比例阀 + 手动微调；
  • 现代方式：电控比例控制，根据露点/氧探头信号自动调节空气或燃气支路。

高思控制 ENDOMATE™ 系列采用电控比例控制系统，官网介绍其作用之一是降低停机风险，并支持多种产气模式以减少排放和能源浪费。

2. 混合气泵

将混合气加压送入反应罐，保证在整个调节范围（产气量从低到高）内都有足够的出口压力。部分设计采用正排量泵以获得稳定流量。

3. 反应罐与催化剂

  • 反应罐：耐热合金离心铸管或焊接管，长期在高温下工作，是发生器寿命最关键的部件之一；
  • 催化剂：通常为载镍的耐火颗粒，填装在反应罐内。催化剂活性下降会导致残余甲烷升高、炭黑增多。

反应罐数量决定产气能力，常见设计从单管到多管，大型发生器单台可达每小时上百立方米。

4. 加热系统

由于裂解吸热，需要外部加热维持反应温度：

  • 电加热：温度控制精确、无燃烧废气，适合对环境要求高的车间；
  • 燃气加热：运行成本可能更低，需要燃烧器和烟气排放管理。

5. 冷却器

出口气体需快速降温，避开约 450–700 °C 的析炭区间。常见方式有水冷换热器和风冷换热器。冷却器积炭或冷却不足会引起炭黑和成分变化。

6. 控制与安全

  • 反应罐温度控制和超温保护；
  • 露点或碳势闭环控制（氧探头或露点传感器）；
  • 燃气低压/高压、空气压力、混合气压力联锁；
  • 火焰检测（燃气加热型）；
  • 启停程序：氮气吹扫、升温、点火、产气、烧炭；
  • 数据记录与报警，满足 CQI-9 对发生器气氛监控的要求。

常见问题

发生器反应罐能用多久？

取决于材质、工作温度、烧炭频率和是否经常冷热循环。规范的温度控制和定期烧炭能显著延长寿命。

电加热和燃气加热发生器如何选？

看当地能源价格、车间排放要求和维护能力。电加热控制更精准、维护简单；燃气加热在燃气便宜的地区运行成本有优势。

发生器能否无人值守运行？

现代发生器可以实现自动控制和远程报警。高思控制 ENDOMATE™ 官网列出了无人值守运行模式、能耗监控和全套数据记录追溯等特点。
