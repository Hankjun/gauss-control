吸热式气氛与 RX 发生器

吸热式气体（Endo / RX 气）的原理、成分与用途

一句话答案

吸热式气体（Endothermic gas，俗称 RX 气、Endo 气）是空气与天然气（或丙烷）按一定比例混合后，在约 1000 °C 以上的镍催化剂反应罐中裂解生成的气体。以天然气为原料时典型成分约为 40% N₂、40% H₂、20% CO，另含少量 CO₂、H₂O 和 CH₄。因反应吸热，需要外部持续供热；生成气成分稳定，是渗碳载气和中性淬火保护气的主流选择。

  • 原料：空气 + 天然气（或丙烷），按固定比例混合
  • 条件：高温（约 1000 °C 以上）+ 镍基催化剂 + 外部加热
  • 产物：约 20% CO、40% H₂、40% N₂（天然气原料）
  • 出口需快速冷却，避免中温区析出炭黑
  • 质量指标：露点 / CO₂、残余 CH₄、成分稳定性

反应原理

吸热式气体的生成可近似表示为（以甲烷为例，空气中 O₂:N₂ ≈ 1:3.76）：

CH₄ + 2.38 × (0.21 O₂ + 0.79 N₂) → CO + 2H₂ + 1.88 N₂

即每份甲烷与约 2.4 份空气反应，生成 CO、H₂ 和 N₂。这一反应整体为吸热反应，必须在发生器反应罐外部持续加热（电加热或燃气加热）才能维持。催化剂一般为载镍的耐火材料，用于使反应在可接受的温度下完全进行并抑制甲烷残留。

实际生产中空气与天然气的比例常在 2.5:1 左右上下微调，用来控制出口气的露点或 CO₂，从而决定气体的“碳势”。

典型成分

组分 天然气原料（约） 丙烷原料（约）
CO 20% 23%
H₂ 40% 31%
N₂ 40% 余量
CO₂ / H₂O / CH₄ 少量，随空燃比变化 少量

天然气原料的成分数据与行业公开资料一致；丙烷原料的数据参考高思控制 CQI-9 碳势管理文章中的对比。

为什么要快速冷却

裂解气离开高温反应区后，若在约 450–700 °C 区间停留过久，会发生 2CO → C + CO₂ 的逆反应，析出炭黑并改变成分。因此发生器出口设有冷却器（水冷或风冷），使气体迅速降温，“冻结”高温下的平衡成分。

主要用途

  • 渗碳 / 碳氮共渗载气：提供稳定的 CO 与 H₂，配合富化气调节碳势；
  • 中高碳钢淬火加热保护：调整露点使碳势与材料含碳量匹配，防止脱碳；
  • 复碳、钎焊、烧结等需要还原性气氛的场合。

由于成分稳定、CO 含量相对恒定，吸热式气氛进入炉内后，CO 和 CO₂ 呈稳定状态、CH₄ 处于较低水平，有利于精确而稳定的碳势控制。这是它相较于氮-甲醇气氛的主要优势。

气体质量看什么

  1. 露点或 CO₂：反映空燃比和气体的碳势水平；
  2. 残余 CH₄：偏高说明催化剂活性下降、反应温度不足或空燃比偏离；
  3. 成分波动：直接影响下游炉内碳势控制精度；
  4. 炭黑：出现炭黑说明需要烧炭或检查冷却。

常见问题

吸热式气体有毒吗？

含约 20% 的 CO，属于有毒、易燃气体。车间需要通风、CO 报警、可靠的安全联锁和规范的点火/吹扫程序。

发生器停机后气体能储存吗？

一般不储存，按需连续生产。需要连续供气时，可采用双炉体发生器一用一备，或多台发生器并联。

RX 是什么意思？

RX 原本是美国 Surface Combustion 公司对吸热式气体的商标性叫法，后来在行业内被广泛用作吸热式气体的代称。
