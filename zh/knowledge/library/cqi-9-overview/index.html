CQI-9 是什么？热处理系统评估的结构与审核重点

一句话答案

CQI-9（Heat Treat System Assessment）是美国汽车工业行动集团 AIAG 发布的热处理系统评估要求，被众多整车厂和一级供应商用于审核热处理供应商。它把热处理视为“特殊过程”，要求从管理职责与质量策划、现场与物料管理、设备三个方面建立体系，并按工艺类型对温度、气氛、淬火、记录和检验提出具体要求。企业通常需每年进行自评，并接受客户审核。

  • 发布方：AIAG；对象：汽车行业热处理（自有及外协）
  • 核心理念：热处理是特殊过程，必须过程受控而不只靠终检
  • 三大章节：管理与质量策划、现场与物料、设备
  • 过程表：按工艺类型规定参数与监控要求
  • 年度自评 + 作业审核 + 持续改进

为什么会有 CQI-9

热处理结果（层深、组织、硬度梯度）往往无法通过对每个零件的无损检验完全确认。一旦过程失控，缺陷可能在装车后才以疲劳断裂的形式出现。汽车行业因此建立 CQI-9，要求热处理商用体系化的过程控制来保证质量。

适用范围

  • 整车厂和零部件企业的内部热处理车间；
  • 外协商业热处理厂；
  • 覆盖渗碳、碳氮共渗、渗氮、氮碳共渗、淬火回火、退火、感应淬火、铝合金热处理等多种工艺。

主要结构

第一部分：管理职责与质量策划

  • 指定热处理专业负责人；
  • 失效模式分析（FMEA）、控制计划；
  • 内部审核、管理评审、持续改进；
  • 人员培训与资格。

第二部分：现场与物料管理

  • 零件接收、识别、批次隔离与追溯；
  • 装炉方式、零件转移；
  • 不合格品控制与返工规则。

第三部分：设备

  • 高温测量（热电偶、仪表、TUS、SAT）；
  • 气氛控制与监控（碳势、露点、氮势等）；
  • 淬火系统（温度、搅拌、介质检测）；
  • 设备维护和备件。

过程表（Process Tables）

按工艺类型列出必须监控的参数、监控频率和公差，例如碳势、温度、时间、淬火油温等。

审核方式

  1. 系统评估：逐条核对上述要求，评定符合性；
  2. 作业审核（Job Audit）：选择一个具体零件，从接收到发货跟踪全过程，核对实际记录与要求；
  3. 年度自评：企业每年至少自评一次，形成改进计划。

现场审核最常被追问的内容

  • 温度系统：TUS、SAT 报告是否在有效期内，偏差是否在允许范围；
  • 气氛：碳势是否连续监控记录、是否每天用备用方法校验；
  • 淬火：油温、搅拌、介质性能检测记录；
  • 追溯：能否从一个零件追溯到具体炉次和曲线；
  • 变更：工艺和设备变更是否经过评审和验证。

准备建议

  1. 先用最新版 CQI-9 做差距分析；
  2. 优先补齐“连续监控 + 记录 + 校验”三件事；
  3. 把记录电子化，减少纸质记录缺失和篡改风险；
  4. 指定专人负责仪表校准和 TUS/SAT 计划；
  5. 定期做内部作业审核演练。

常见问题

CQI-9 有几个版本？

CQI-9 已多次修订，各版本在条款和过程表上有调整。应使用客户要求的版本，一般为当前最新版本。

CQI-9 是认证吗？

它不是第三方认证证书，而是评估要求。客户会要求供应商自评并接受审核，结果用于供应商管理。

小型热处理厂也要满足 CQI-9 吗？

只要为汽车行业客户提供热处理，客户通常会要求。可以从关键工艺和关键设备开始，逐步完善。
