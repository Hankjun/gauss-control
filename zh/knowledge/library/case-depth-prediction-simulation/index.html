渗碳与碳势控制

渗碳层深预测与在线扩散计算：从经验到模型

一句话答案

渗碳层深预测的基础是菲克第二定律：用随温度和含碳量变化的扩散系数，结合表面碳传递边界条件，逐时步计算碳浓度分布。离线模拟用于设计和优化工艺；在线扩散计算则把实时温度和碳势输入模型，动态估算当前层深和表面碳，可在达到目标时自动结束渗碳。模型需用实测数据校准，才能可靠指导生产。

  • 基础模型：菲克第二定律 + 碳传递边界条件
  • 离线模拟：设计工艺、缩短试错
  • 在线计算：用实时温度和碳势估算当前层深
  • 输入：材料成分、温度曲线、碳势曲线、气氛类型
  • 必须用金相/硬度实测校准

为什么需要模型

传统渗碳工艺多依赖经验表格和试样。问题在于：

  • 实际生产中温度和碳势不是理想的阶梯，开门、升温、恢复都会影响结果；
  • 换材料、换层深要求时需要反复试验；
  • 无法在过程中知道“现在渗到多深了”。

扩散模型可以把这些因素量化。

基本模型

碳在奥氏体中的扩散遵循菲克第二定律：

∂C/∂t = ∂/∂x (D(C, T) · ∂C/∂x)

  • D 为扩散系数，随温度呈指数增长，也随含碳量变化；
  • 表面边界条件：碳流量 = β × (CP − C_surface)，β 为碳传递系数；
  • 初始条件：基体含碳量。

数值求解后得到每个时刻的碳浓度—深度曲线，再结合材料淬透性估算硬度分布和有效硬化层深度。

离线模拟 vs 在线计算

维度 离线模拟 在线扩散计算
输入 计划的温度、碳势和时间 控制器实时采集的温度和碳势
用途 工艺设计、优化、培训 过程监控、动态结束、质量记录
时机 生产前 生产中
价值 减少试错 补偿过程扰动，提高一致性

模型输入清单

  1. 材料化学成分（用于扩散系数和合金修正）；
  2. 初始含碳量；
  3. 温度曲线（含升温、均温、降温）；
  4. 碳势曲线（强渗、扩散）；
  5. 气氛类型（影响碳传递系数）；
  6. 目标：表面碳、层深判据（如 0.35% C 或 550 HV）。

校准与验证

模型不是“开箱即准”：

  • 用典型零件的金相和硬度梯度实测结果对比模型输出；
  • 调整碳传递系数、合金因子等参数；
  • 对不同炉型、装炉量分别验证；
  • 定期复核，尤其在更换气氛来源或炉子大修后。

应用价值

  • 新零件工艺开发周期缩短；
  • 根据实际过程动态调整扩散时间，减少层深波动；
  • 为每炉生成碳浓度曲线记录，支持追溯和客户审核。

常见问题

模拟结果能替代金相检验吗？

不能。模拟用于预测和控制，最终质量仍需按规范做金相、硬度检验。但良好的模型可以减少检验频次和返工。

在线计算需要额外传感器吗？

通常不需要，利用控制系统已有的温度和碳势数据即可，但数据质量直接决定计算准确性。

大截面零件能用同一个模型吗？

扩散模型适用，但大截面零件升温慢、表面与心部温度差大，需要用零件实际温度（或热电偶实测）作为输入。
