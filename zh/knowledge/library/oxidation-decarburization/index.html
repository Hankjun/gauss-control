热处理与可控气氛基础

氧化与脱碳：成因、危害与防止方法

一句话答案

氧化是钢表面的铁与 O₂、H₂O、CO₂ 反应生成氧化物；脱碳是表层碳与这些氧化性气体反应生成 CO 或 CH₄ 而流失。二者都会导致表面硬度降低、疲劳寿命下降和尺寸损失。防止的核心是让炉内气氛的氧化性足够低、碳势与钢的含碳量匹配，并确保炉体密封和气氛稳定。

  • 氧化性来源：空气渗入、气氛中 H₂O 和 CO₂ 偏高
  • 脱碳层会使表面硬度不足，是齿轮、弹簧疲劳失效的常见原因
  • 防止方法：可控气氛、碳势匹配、密封、合理装炉和快速转移
  • 检测：金相法、显微硬度梯度法

氧化：生成氧化皮

在高温下，铁与氧化性气体反应：

  • 2Fe + O₂ → 2FeO
  • Fe + H₂O ⇌ FeO + H₂
  • Fe + CO₂ ⇌ FeO + CO

当气氛中 H₂O/H₂ 或 CO₂/CO 的比值超过某温度下的临界值，钢表面就会氧化。这就是为什么保护气氛中要有足量还原性组分（H₂、CO），并控制水分和二氧化碳。

脱碳：表层碳的流失

脱碳的主要反应包括：

  • [C] + O₂ → CO₂ / CO
  • [C] + H₂O → CO + H₂
  • [C] + CO₂ → 2CO
  • [C] + 2H₂ ⇌ CH₄（在高温、干燥氢气中也可能发生）

只要炉内碳势低于钢的含碳量，碳就会向外扩散。脱碳可分为全脱碳（表层几乎全为铁素体）和部分脱碳（含碳量低于基体）。

危害

  • 表面淬火后硬度不足，出现“软点”；
  • 表层残余压应力减小甚至变为拉应力，疲劳寿命大幅下降，对弹簧、齿轮、轴类尤其敏感；
  • 氧化皮导致尺寸损失和加工余量增加；
  • 晶界氧化（内氧化）会成为疲劳裂纹源。

如何防止

  1. 使用可控气氛并匹配碳势：淬火加热时把碳势设在材料含碳量附近；
  2. 保证炉体密封：炉门、炉帘、热电偶套管、风扇轴等处的漏气是空气进入的主要途径；
  3. 稳定的气氛来源：吸热式发生器、氮-甲醇系统的波动会直接表现为碳势波动；
  4. 监测与报警：通过氧探头和分析仪及时发现异常；
  5. 工艺细节：减少零件出炉到淬火的转移时间、避免在中温区长时间停留。

如何检测

  • 金相法：截面腐蚀后观察铁素体层和组织变化；
  • 显微硬度法：从表面向内测硬度梯度，判断脱碳层深度；
  • 化学分析：逐层剥离或火花光谱分析表层含碳量。

常见问题

用纯氮保护能防止脱碳吗？

纯氮可以减少氧化，但氮气中微量的氧和水分在高温下仍可能导致脱碳，且纯氮不具备“复碳”能力。对高碳钢和对表面碳要求严格的零件，建议使用碳势可控的气氛。

脱碳层可以修复吗？

可以通过复碳处理（在碳势略高于材料含碳量的气氛中重新加热）恢复表面含碳量，但成本高、效果需验证，最好的办法是在源头防止。

网带炉出口零件发蓝发黑说明什么？

通常说明冷却段或出口处有空气进入或水分偏高，导致轻微氧化。应检查出口火帘、冷却段密封和气氛流量。
