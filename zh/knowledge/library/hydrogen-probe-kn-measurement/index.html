渗氮与氮势控制

氨分解率、氢探头与 Kn 测量：原理、方法与选型

一句话答案

渗氮气氛测量有三种主要方式：传统的水吸收式分解率计（手动、离线）、氢探头（常用热导法测 H₂ 分压）和氨分析仪（红外等方法测 NH₃）。在只通氨或氨+已知稀释气时，由 H₂ 含量结合物料守恒可算出 NH₃ 分压，进而得到 Kn = p(NH₃)/p(H₂)^1.5。氢探头因结构简单、可连续测量，成为可控渗氮的主流传感器。

  • 分解率计：手动、离线，只能间接反映渗氮能力
  • 氢探头：热导法测 H₂，连续、可闭环
  • 氨分析仪：直接测 NH₃，成本较高
  • 只通氨时：H₂ 测得 → NH₃ 由守恒算出 → 计算 Kn
  • 取样管路低温结晶是常见故障

三种测量方式

方式 原理 优点 局限
分解率计（玻璃滴定管式） 取样气通过水，氨被吸收，剩余体积即为分解产物比例 便宜、直观 手动、离线、精度受操作影响，无法闭环
氢探头 热导法测 H₂ 分压（H₂ 导热性远高于其他组分） 连续测量、可闭环、维护简单 需考虑其他气体对热导的干扰
氨分析仪 红外等方法直接测 NH₃ 直接测量氨 成本较高、需维护取样系统

从 H₂ 到 Kn

只通氨时，氨部分分解：

2NH₃ → N₂ + 3H₂

设进入炉内的氨中分解比例为 α，则炉气中：

  • H₂ 体积分数 = 1.5α / (1 + α)
  • NH₃ 体积分数 = (1 − α) / (1 + α)
  • N₂ 体积分数 = 0.5α / (1 + α)

测得 H₂ 后即可反推 α 和 NH₃，进而计算 Kn。加入氮气或预分解氨稀释时，只要已知各进气流量，同样可以通过物料平衡求解。这就是“氢探头 + 流量测量 + 计算”的可控渗氮基本架构。

氢探头的热导原理

不同气体的热导率差异很大，H₂ 的热导率约为 N₂ 的 7 倍左右。热导传感器测量加热元件在被测气体中的散热情况，由此推算 H₂ 含量。

现场常见问题

  1. 低温结晶堵塞：在氮碳共渗（软氮化）中，气氛含 CO₂，取样气温度降低后，氨与 CO₂ 会生成碳酸氢铵等坚硬固体，堵塞取样管。高思控制 Nitromate H2 Probe II 官网介绍，其核心元器件设计解决了温度低于约 65 °C 后碳酸氢铵堵塞管道的问题；
  2. 取样位置：应代表工件区气氛，避开进气口；
  3. 泄漏：取样管路漏气会稀释样气，导致 H₂ 读数偏低；
  4. 交叉干扰：气氛中其他组分（如 CO₂、CO）会影响热导测量，需要算法补偿。

选型要点

  • 适用工艺（渗氮 / 氮碳共渗）；
  • 安装方式和炉型适配（井式、箱式、多用炉）；
  • 是否具备抗结晶设计；
  • 与控制器的信号接口和计算能力。

常见问题

有了氢探头还需要分解率计吗？

不是必须的，但分解率计可作为简便的交叉验证手段，在审核或故障排查时有用。

氢探头需要多久校准一次？

按厂家建议和使用强度确定，并在更换、维修或发现读数异常后校准。校准用已知浓度的标准气。

为什么不同厂家的 Kn 值对不上？

计算方法（是否考虑稀释气、压力单位）、取样位置和传感器差异都会造成不同。比较时应统一定义和计算方式。
