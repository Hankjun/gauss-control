渗氮与氮势控制

氨分解器：原理、气体成分与在热处理中的应用

一句话答案

氨分解器把液氨气化后，在约 900 °C 以上的镍基催化剂中分解为 75% H₂ 和 25% N₂ 的混合气（2NH₃ → N₂ + 3H₂）。这种气体强还原性、成本相对较低，广泛用于不锈钢和硅钢光亮退火、钎焊、粉末冶金烧结，以及在渗氮中作为稀释气调节氮势。关键质量指标是残余氨和露点，关键安全要点是氢气的防爆管理。

  • 反应：2NH₃ → N₂ + 3H₂，产物 75% H₂ + 25% N₂
  • 条件：高温 + 镍基催化剂
  • 用途：光亮退火、钎焊、烧结、渗氮稀释调 Kn
  • 质量指标：残余 NH₃、露点
  • 安全：氢气易燃易爆，需泄漏检测和联锁

原理

液氨经汽化器变为气态氨，进入加热到高温的反应罐，在镍基催化剂作用下分解：

2NH₃ → N₂ + 3H₂

完全分解后，气体组成为 75% H₂、25% N₂（体积比）。反应为吸热反应，需要外部加热维持温度。

主要组成

  1. 液氨汽化系统：将液氨转化为稳定压力的气态氨；
  2. 反应罐与催化剂：完成分解反应；
  3. 加热系统：电加热为主；
  4. 冷却器：冷却产物气；
  5. 净化装置（可选）：干燥器去除水分、降低露点，必要时去除残余氨；
  6. 控制与安全：温度控制、压力控制、氢气泄漏报警。

质量指标

指标 意义
残余氨 反应温度不足或催化剂活性下降时升高；对光亮退火不利
露点 水分高会导致不锈钢等材料表面氧化发暗
流量稳定性 影响下游炉内气氛

应用

1. 光亮退火 不锈钢、硅钢、铜合金等在高还原性氢氮气氛中退火，表面保持光亮。

2. 钎焊与烧结 提供还原性气氛，去除表面氧化物，改善润湿和结合。

3. 渗氮中的稀释与 Kn 调节 在渗氮中，向炉内通入预分解的氨（氢氮混合气）可以在不改变温度的情况下降低氮势，实现对 Kn 的精细控制，尤其在需要低 Kn 或无化合物层渗氮时有用。

安全要点

  • 液氨属于危化品，储存和使用需符合相关安全规范；
  • 产物含 75% 氢气，易燃易爆，管路需防泄漏，车间需氢气报警和通风；
  • 进炉前需确认炉温达到安全温度或采用氮气吹扫；
  • 停机时用氮气置换管路。

常见问题

氨分解气和纯氢比有什么优势？

成本相对较低，供应稳定；含 25% 氮气，可燃性风险相对纯氢略低。但仍需严格按氢气安全规范管理。

残余氨偏高怎么处理？

检查反应温度、催化剂活性和流量是否超出设计能力；必要时更换催化剂或降低负荷。

渗氮炉能否直接用氨分解器的气体调节 Kn？

可以。这是常见的 Kn 调节方式之一，需与控制系统配合，按 Kn 设定值自动调节氨气与分解气的比例。
