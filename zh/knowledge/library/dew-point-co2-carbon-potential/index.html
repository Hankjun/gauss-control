热处理与可控气氛基础

露点、CO₂ 与碳势：三种指标如何换算与取舍

一句话答案

在吸热式或氮-甲醇气氛中，H₂O（以露点表示）、CO₂ 和氧分压通过水煤气反应和边界反应互相关联。只要气氛接近平衡、CO 与 H₂ 含量稳定，三者中任一项加上温度都能换算出碳势。露点常用于发生器出口控制，CO₂ 红外分析适合校验和诊断，氧探头响应最快，最适合炉内实时闭环控制。

  • 露点越低、CO₂ 越低、氧分压越低 → 碳势越高
  • 三者通过 CO + H₂O ⇌ CO₂ + H₂ 平衡相互关联
  • 发生器出口常控露点，炉内常用氧探头控制
  • 气氛偏离平衡（如残余 CH₄ 高）时，单一指标换算会失真

三个指标背后的同一组反应

吸热式气氛主要由 CO、H₂、N₂ 组成，并含少量 CO₂、H₂O 和 CH₄。与碳势有关的主要平衡是：

  • 边界反应：2CO ⇌ [C] + CO₂
  • 水煤气反应：CO + H₂ ⇌ [C] + H₂O
  • 水煤气变换：CO + H₂O ⇌ CO₂ + H₂

当气氛接近平衡时，CO₂、H₂O 与氧分压是“同一个信息”的三种表达：知道其中一个，再知道温度和 CO（及 H₂）含量，就能推出另外两个和碳势。

三种测量方式比较

指标 测量手段 优点 局限
露点（H₂O） 露点仪、冷镜、电容式传感器 直观，适合发生器出口气体质量监控 取样管路易冷凝、响应慢；不能单独给出碳势
CO₂ 红外（NDIR）分析仪 可同时测 CO、CH₄，诊断能力强，便于校验 需取样、需定期标定；仪器成本较高
氧分压 氧化锆氧探头（插入式） 原位测量、响应快，最适合炉内闭环控制 探头会老化、积炭，需维护与校验

实际应用中的分工

  • 发生器出口：以露点或 CO₂ 控制空气/燃气比例，保证 RX 气质量稳定；
  • 炉内碳势控制：以氧探头为主信号，结合温度和设定 CO% 计算碳势，实时调节富化气或稀释空气；
  • 日常校验与诊断：用三气分析仪测 CO、CO₂、CH₄，对比控制器显示碳势，判断探头和气氛状态。

常见误区

  1. 只看露点就判断碳势：同样露点下，温度和 CO 含量不同，碳势也不同；
  2. 忽略 CH₄：甲烷含量高说明气氛偏离平衡，基于平衡关系的换算会偏差，这在氮-甲醇+丙烷富化气氛中较常见；
  3. 取样管路冷凝：露点和 CO₂ 取样管若温度过低或泄漏，读数会严重失真。

常见问题

发生器出口露点一般控制在多少？

取决于下游工艺所需碳势。用于渗碳载气时通常保持较低露点；用于中性淬火加热时按材料含碳量对应的碳势选择。应根据工艺要求设定，而不是固定一个值。

有了氧探头还需要红外分析仪吗？

建议配备。氧探头负责实时控制，红外分析仪负责校验和诊断（如测 CO% 是否偏离设定值、CH₄ 是否偏高），二者互补，也有助于满足 CQI-9 的备用验证要求。

露点读数波动大是什么原因？

常见原因包括取样管路漏气或冷凝、发生器空气/燃气比例波动、催化剂积炭或老化，以及传感器污染。应先排查取样系统，再看发生器状态。
