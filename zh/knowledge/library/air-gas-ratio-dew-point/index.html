吸热式气氛与 RX 发生器

空燃比如何决定 RX 气的露点与碳势：调节原理与实践

一句话答案

在吸热式发生器中，空气比例越高，出口气中 H₂O 和 CO₂ 越多，露点越高、碳势越低；空气比例越低，露点越低、碳势越高，但残余甲烷和炭黑风险上升。通过氧探头或露点传感器闭环调节空燃比，可以让 RX 气的碳势稳定在下游工艺需要的范围。

  • 多一点空气 → 露点升高、碳势下降
  • 少一点空气 → 露点降低、碳势升高，但 CH₄ 和炭黑风险上升
  • 控制方式：手动比例阀 → 自动闭环（氧探头或露点）
  • 稳定的空燃比是下游碳势精度的前提

关系一句话

空燃比是发生器的“碳势旋钮”。空气多，氧化性组分（H₂O、CO₂）多，露点高，碳势低；空气少，反之。

化学解释

理论配比下（以天然气为例约 2.4 份空气对 1 份甲烷），产物主要是 CO、H₂ 和 N₂。

  • 当空气略多于理论值，多余的氧使部分 H₂ 和 CO 进一步氧化为 H₂O 和 CO₂，露点上升；
  • 当空气略少于理论值，甲烷裂解不完全，残余 CH₄ 增加，气体的碳势更高，同时更容易析出炭黑。

下游工艺如何决定设定值

下游用途 对 RX 气的要求
渗碳载气 气体本身碳势通常略低于目标碳势，由炉内富化气提高
中碳钢淬火加热 RX 气碳势接近材料含碳量（如 0.4% 左右）
高碳钢 / 轴承钢淬火 需要较低露点、较高碳势

因此“发生器露点设多少”没有统一答案，而应由下游工艺推导。

调节方式

手动调节：通过比例阀或针阀调整空气或燃气，用露点仪定期检测。缺点是燃气热值、压力和环境温度变化会导致漂移。

自动闭环调节：在发生器出口安装氧探头或露点传感器，控制器根据测量值自动调节空气（或燃气）支路，使露点/碳势稳定在设定值。这是目前主流做法。

影响稳定性的因素

  1. 燃气成分和热值波动：天然气组分变化会改变理论空燃比；
  2. 供气压力波动：影响流量计和比例阀的实际比例；
  3. 催化剂活性：积炭或老化使同样空燃比下残余 CH₄ 升高；
  4. 反应温度：温度不足导致反应不完全；
  5. 产气量变化：低负荷和高负荷时最佳空燃比略有差异。

现场经验

  • 调整幅度要小、要等待稳定后再判断，避免来回振荡；
  • 同时看露点和 CH₄，单看露点可能掩盖催化剂问题；
  • 记录调节前后的数据，形成发生器“健康档案”。

常见问题

为什么空燃比没变，露点却慢慢升高？

常见原因有催化剂积炭（需烧炭）、燃气成分变化、比例阀磨损或取样管路泄漏。先检查取样和传感器，再检查催化剂。

发生器出口用氧探头还是露点仪控制好？

氧探头响应快、适合闭环；露点仪直观、便于校验。很多系统用氧探头控制、用露点仪或红外分析仪定期验证。

低负荷运行时有什么要注意？

低负荷时气体在反应罐内停留时间变化，空燃比需要相应微调；长期低负荷可考虑多种产气模式或合理选型，避免能源浪费。
