渗氮与氮势控制

氮碳共渗（软氮化 / FNC）：原理、气氛控制与后氧化

一句话答案

铁素体氮碳共渗（FNC，俗称软氮化）在约 560–590 °C 进行，气氛以氨为主，加入 CO₂、吸热式气或其他含碳气体，在较短时间内形成以 ε 相为主的化合物层和薄扩散层，显著提高耐磨、抗咬合和耐蚀性能。控制要点是同时管理氮势与碳活度；后氧化处理可在表面形成致密的 Fe₃O₄ 层，进一步提升耐蚀性。

  • 温度约 560–590 °C，处于铁素体状态
  • 气氛：NH₃ + 含碳气体（CO₂、吸热式气等）
  • 结果：以 ε 相为主的化合物层，处理时间相对较短
  • 控制：氮势与碳活度双重管理
  • 后氧化提升耐蚀性；取样管易生成碳酸氢铵结晶

与渗氮的区别

项目 气体渗氮 氮碳共渗（FNC）
温度 约 500–580 °C 约 560–590 °C
气氛 NH₃（+稀释气） NH₃ + 含碳气体
时间 较长 较短（常为几小时）
主要目标 扩散层深度、疲劳强度 化合物层：耐磨、抗咬合、耐蚀
典型零件 曲轴、齿轮、模具 汽车零件、液压件、紧固件、普通结构件

原理

碳的加入促进 ε 相的形成和稳定，使化合物层更快、更厚地生长。因此 FNC 在较短时间内即可获得性能良好的化合物层，适合低碳钢和普通碳钢零件。

气氛组成与控制

常见气氛组合：

  • NH₃ + CO₂；
  • NH₃ + 吸热式气；
  • NH₃ + N₂ + CO₂ 等。

控制需要同时考虑：

  1. 氮势 Kn：决定氮的吸收和相组成；
  2. 碳活度：影响 ε 相中的碳含量和化合物层质量；
  3. 气体比例与流量：保证炉内各处成分均匀。

后氧化

FNC 后，在控制条件下用氧化性气氛（如水蒸气、空气或 N₂O）对表面进行氧化，形成致密的 Fe₃O₄ 黑色氧化层，可显著提高耐盐雾性能，同时外观美观。工艺温度、时间和气氛需严格控制，避免形成疏松的 Fe₂O₃。

常见问题

软氮化和盐浴氮化有什么区别？

盐浴氮碳共渗用熔融盐作为介质，速度快、均匀性好，但存在废盐处理和环保问题。气体氮碳共渗更清洁，便于自动控制和记录。

FNC 后需要淬火吗？

一般不需要。它在铁素体状态下进行，渗后可直接冷却（油冷、水冷或气冷，按工艺要求）。

不锈钢可以做软氮化吗？

可以，但不锈钢表面钝化膜会阻碍渗氮，需要专门的活化处理，而且会降低其本身的耐蚀性，需评估使用场景。
