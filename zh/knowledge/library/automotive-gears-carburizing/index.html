汽车零部件热处理：齿轮与轴类渗碳的质量控制要点

一句话答案

汽车齿轮和轴类零件的热处理质量特性包括有效硬化层深度、表面与心部硬度、表面碳含量、金相组织（碳化物、残余奥氏体、内氧化）和变形。保证一致性的关键是稳定的载气、准确的碳势控制与每日校验、温度系统精度、规范的淬火管理和完整的追溯记录，这些也正是 CQI-9 的审核重点。

  • 关键特性：有效硬化层、硬度、表面碳、组织、变形
  • 气氛：稳定载气 + 碳势闭环 + 每日校验
  • 温度：TUS、SAT、热电偶管理
  • 淬火：油温、搅拌、转移时间
  • 追溯：零件到炉次曲线；满足 CQI-9

汽车零件为什么对热处理特别敏感

变速箱齿轮、差速器齿轮、传动轴、凸轮轴等承受交变载荷和接触应力，失效模式主要是弯曲疲劳、接触疲劳（点蚀、剥落）和磨损。这些性能高度依赖表层组织和残余应力，而它们由渗碳淬火过程决定。

过程控制重点

1. 气氛 - 使用成分稳定的载气（吸热式 RX 气或严格控制的氮-甲醇）； - 氧探头闭环控制碳势，并管理探头寿命； - 每日用三气分析、热丝或定碳片校验碳势。

2. 温度 - 按要求进行 TUS、SAT； - 热电偶建立使用记录。

3. 淬火 - 油温、搅拌速度、介质冷却特性定期检测； - 出炉到淬火的转移时间受控。

4. 装炉 - 标准化装炉方式，减少变形和软点。

5. 记录与追溯 - 每炉次碳势、温度、淬火曲线电子化保存； - 零件批次与炉次绑定。

可控气氛方案参考

  • 多用炉线：集中供气 RX 发生器 + 每台炉独立碳势控制 + 自动线调度；
  • 网带炉（紧固件、小件）：双炉体发生器保证连续供气；
  • 推杆炉（大批量齿轮）：分区碳势控制 + 在线扩散计算。

常见问题

齿轮渗碳层深一般要求多少？

由齿轮模数、载荷和设计确定，图纸会给出有效硬化层范围。通常模数越大，层深要求越深。

汽车零件可以用低压真空渗碳吗？

可以，尤其是高端变速箱齿轮。低压渗碳可避免内氧化，配合高压气淬变形小，但投资和运行成本较高。

内氧化深度有要求吗？

很多汽车零件规范对内氧化（晶界氧化）深度有上限要求，需通过控制气氛氧化性和工艺满足。
