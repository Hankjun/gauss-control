渗碳与碳势控制

气体渗碳原理：三个主反应、碳传递与扩散

一句话答案

气体渗碳包括两个串联过程：一是气氛中的碳通过化学反应传递到钢表面（受碳势和碳传递系数控制），二是碳从表面向内部扩散（受温度、时间和钢的扩散系数控制）。主要反应有甲烷反应 CH₄ → [C] + 2H₂、边界反应 2CO → [C] + CO₂ 和水煤气反应 CO + H₂ → [C] + H₂O。在载气中残余甲烷很低、气氛接近平衡时，碳势可以用边界反应或水煤气反应来表征。

  • 两步过程：表面碳传递 + 内部扩散
  • 三个主反应：甲烷反应、边界反应、水煤气反应
  • 载气接近平衡时，用 CO/CO₂ 或 CO/O₂ 关系计算碳势
  • 渗速受温度、碳势、碳传递系数和钢种共同影响

两个串联过程

  1. 碳的传递（表面反应）：气氛中的含碳组分在钢表面分解，把碳“交给”钢。速度取决于气氛碳势与表面含碳量之差，以及碳传递系数 β。
  2. 碳的扩散（固态扩散）：碳从高浓度的表面向低浓度的心部扩散，遵循菲克定律。速度主要取决于温度（扩散系数随温度指数增长）和时间。

渗碳工艺设计就是在这两者之间寻找平衡：既要表面供碳充足，又要避免表面碳过高。

三个主反应

反应 方程 说明
甲烷反应 CH₄ → [C] + 2H₂ 富化气（天然气、丙烷）提供碳，反应较慢
边界反应（Boudouard） 2CO → [C] + CO₂ CO 是主要供碳组分
水煤气反应 CO + H₂ → [C] + H₂O 速度快，是渗碳的主要途径之一

另外，气氛中存在连续的水煤气变换反应 CO + H₂O ⇌ CO₂ + H₂，把 H₂O 与 CO₂ 联系在一起。

在设计气氛时，一般把载气进入后的残余甲烷控制得很低，使气氛接近化学平衡并保持稳定。此时碳的传递可以用水煤气反应或边界反应来表征，这正是氧探头、CO₂ 分析仪能够计算碳势的理论基础。

碳传递系数 β

即使碳势相同，不同气氛向钢表面传递碳的速度也不同。β 与 CO 和 H₂ 的分压乘积大致相关，因此：

  • 纯甲醇裂解气（CO、H₂ 都高）传递最快；
  • 吸热式气与氮-甲醇（约 20% CO、40% H₂）居中；
  • 稀释后的气氛（N₂ 比例高）传递更慢。

影响渗速的因素

  1. 温度：最显著。提高温度能大幅缩短渗碳时间，但会带来晶粒长大和变形增加；
  2. 碳势：碳势越高，表面碳浓度越高，扩散驱动力越大；
  3. 气氛类型：决定碳传递系数；
  4. 钢种：合金元素影响碳在奥氏体中的溶解度与扩散；
  5. 装炉与气氛循环：影响零件各处的气氛均匀性。

常见问题

渗碳温度一般多少？

常规可控气氛渗碳多在 900–950 °C 之间，常见 920–930 °C。高温渗碳可缩短时间，但需关注晶粒度和变形。

富化气用天然气还是丙烷？

两者都可以。丙烷含碳多、富化能力强、用量少；天然气更易获得且燃烧产物更清洁。选择取决于当地供应和控制系统的设定。

为什么渗碳后还要淬火？

渗碳只是提高表层含碳量，必须淬火形成高碳马氏体，表面才会获得高硬度；随后低温回火以降低脆性。
