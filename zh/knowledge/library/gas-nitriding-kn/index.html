渗氮与氮势控制

气体渗氮原理与氮势 Kn：为什么要控制 Kn 而不只是分解率

一句话答案

气体渗氮是在约 500–580 °C 的铁素体状态下，利用氨气在钢表面分解产生的活性氮渗入表层，形成化合物层和扩散层。氮势 Kn = p(NH₃) / p(H₂)^1.5，直接决定氮在钢表面的活度和能形成哪种相。传统做法只控制氨分解率，但分解率与 Kn 的关系会随稀释气和炉况变化；以 Kn 为控制目标的可控渗氮能更精确地控制化合物层厚度和相组成。

  • 渗氮温度约 500–580 °C，钢处于铁素体状态，无相变、变形小
  • 反应：2NH₃ → 2[N] + 3H₂
  • Kn = p(NH₃) / p(H₂)^1.5，单位 bar^-0.5
  • 分解率只是间接指标，Kn 才直接决定表面氮活度
  • 可控渗氮可精确控制白亮层厚度与相组成

渗氮的基本过程

氨气进入炉内后，在钢表面（铁起催化作用）发生分解：

2NH₃ → 2[N] + 3H₂

分解产生的活性氮原子一部分渗入钢中，一部分结合成 N₂ 离开。渗入的氮：

  • 在表面达到一定浓度后形成化合物层（ε-Fe₂₋₃N 和/或 γ′-Fe₄N，俗称白亮层）；
  • 在化合物层下方以固溶和合金氮化物析出的形式形成扩散层。

由于温度低于钢的相变温度，渗氮过程中无相变，零件变形小，渗后通常不需要淬火。

氮势 Kn 的定义

Kn = p(NH₃) / p(H₂)^1.5

p 为炉气中氨和氢的分压（bar 或 atm），因此 Kn 单位为 bar^-0.5。

Kn 越高，气氛的渗氮能力越强，越容易形成化合物层甚至 ε 相；Kn 越低，越倾向于只形成扩散层或 γ′ 相。

为什么不只看分解率

传统渗氮通过测“氨分解率”控制工艺：分解率低意味着未分解氨多，渗氮能力强。但分解率与 Kn 之间并不是固定关系：

  • 加入 N₂ 或预分解氨稀释时，同样分解率对应的 Kn 不同；
  • 炉内温度、装炉面积（催化表面）、气体流量都会影响分解率；
  • 分解率测量（传统的水吸收法分解率计）精度和自动化程度有限。

因此，以 Kn 为控制变量，通过测量氢（或氨）含量实时计算 Kn，并调节氨气与稀释气比例，是可控渗氮的核心。

可控渗氮的优势

  1. 精确控制化合物层厚度和相组成（ε / γ′）；
  2. 可以实现“无化合物层”的扩散层渗氮；
  3. 工艺可重复，适合航空航天、风电、汽车等要求高的领域；
  4. 节约氨气，减少排放；
  5. 满足 AMS2759/10 等以氮势控制为核心的规范。

常见问题

渗氮层一般有多深？

气体渗氮的扩散层通常在零点几毫米量级，具体取决于材料、温度和时间。渗氮时间往往较长（十几到几十小时甚至更长）。

所有钢都能渗氮吗？

大多数钢都可以渗氮，但含 Cr、Mo、Al、V 等氮化物形成元素的钢（如 38CrMoAl、42CrMo、H13 等）渗氮效果更好、硬度更高。

Kn 能直接用传感器测吗？

Kn 是计算值。通常用氢探头测 H₂ 分压，结合氨与氢的质量守恒关系计算 NH₃ 分压，再得出 Kn；也可用分析仪测 NH₃。
